SWASTHRAHI — SINGLE-URL FULL-STACK SETUP

The frontend and backend are served by one FastAPI web service. The browser calls
same-origin /api/... endpoints; there is no separate frontend URL and no CORS setup.

LOCAL RUN (Python 3.10+ and Node.js 18+ required)
1. Open this project folder in a terminal.
2. Run: npm install
   This installs the Python packages from requirements.txt automatically.
3. Run: npm run dev
4. Open: http://localhost:8000
5. API health: http://localhost:8000/api/health
   API docs:   http://localhost:8000/docs

Only these two project commands are needed after Node.js and Python are installed:
  npm install
  npm run dev

RENDER — ONE WEB SERVICE
- Push this folder (the folder containing package.json and render.yaml) to GitHub.
- In Render choose New > Blueprint and select the repository.
- Render reads render.yaml and creates ONE web service for both frontend and API.
- The service build command installs Node/npm and Python requirements; start command is npm run start.
- Use the single Render URL for the website and its /api endpoints.
- The Blueprint includes a persistent disk for SQLite data and uploads. Render persistent disks
  require a paid service plan; the configured plan is Starter. Do not remove the disk if you need
  uploaded documents and database records to survive deploys/restarts.

ENVIRONMENT
- SWASTHRAHI_SECRET is generated by the Render Blueprint. Locally, set a long random value if
  you need stable signed sessions across restarts.
- PORT is supplied by Render automatically.
- SWASTHRAHI_DATA_DIR controls the SQLite database and uploads directory.

IMPORTANT DEMO / PRODUCTION NOTES
This project contains healthcare-related data. The current API has demo endpoints that are not
all protected by user/staff roles; the emergency request endpoint records a request but does not
dispatch an ambulance or contact a hospital. Email verification and password-reset emails are
not configured. Review authorization, consent, audit logging, encryption, backups, rate limiting,
privacy and applicable Indian health-data requirements before using real patient information.
The local SQLite database is created automatically. Keep the persistent disk attached on Render.
